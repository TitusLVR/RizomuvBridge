# Welcome to RizomUV Bridge

**RizomUV Bridge** connects **Autodesk 3ds Max** with **RizomUV** by RizomLabs, enabling a seamless and efficient workflow for UVW channel exchange.

![Bridge Interface](https://via.placeholder.com/800x400?text=RizomUV+Bridge+Interface)

## Key Features

*   **Seamless Transfer**: Send objects from 3ds Max to RizomUV with a single click.
*   **Automatic Sync**: Updates UVs automatically when you save in RizomUV.
*   **Automation Tools**: Run common RizomUV operations (Pack, Unfold, Optimize) directly from 3ds Max.
*   **Scripting Support**: Run custom Lua scripts on your geometry within RizomUV.
*   **Format Choice**: Support for both **FBX** and **USD** (Universal Scene Description) formats.

## Quick Start

1.  **Select** your object in 3ds Max.
2.  Click **"Send"** to open it in RizomUV.
3.  **Unwrap** your model.
4.  Click **"Save"** in RizomUV to update the object in 3ds Max.
