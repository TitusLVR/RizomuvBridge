# Installation

## System Requirements

*   **Autodesk 3ds Max**: Versions 2020, 2021, 2022 (Newer versions like 2024/2025 likely supported but verify first).
*   **RizomUV**: Version 2021, 2022 or newer (VS or MK versions).
*   **OS**: Windows 10/11.

## Installation Steps

There are two primary ways to install the RizomUV Bridge:

### Method 1: Drag and Drop (Recommended)

1.  Locate the `.mzp` file in the downloaded package (e.g., `RizomUVBridge.mzp`).
    *   *Note: If you have the raw files, you might need to run the `install.ms` script manually or create an MZP package.*
2.  **Drag and drop** the file directly into an active 3ds Max viewport.
3.  An installation dialog may appear confirming the successful installation.

### Method 2: Run Script

1.  Open 3ds Max.
2.  Go to **Scripting** > **Run Script...** in the main menu.
3.  Navigate to the RizomUV Bridge `.mzp` file (or `install.ms`) and select it.

## Post-Installation

Once installed:
1.  Navigate to **Customize** > **Customize User Interface**.
2.  Go to the **Toolbars** tab.
3.  Find the category **"RizomUV Bridge"** (or similar, depending on how the macro is named, usually under `TitusLVR`).
4.  Drag the **RizomUV** command to a toolbar of your choice.
5.  You should see the RizomUV icon ready to use.

!!! note "Permissions"
    You may need **Administrator rights** to install scripts into certain 3ds Max directories. If installation fails, try running 3ds Max as Administrator.
